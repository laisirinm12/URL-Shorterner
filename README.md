# URL Shortener

This is a simple **URL Shortener with Analytics Dashboard** built using **HTML, CSS JavaScript and a Node.js API**.  
The application allows users to convert long URLs into short links, track click analytics and manage links through an interactive dashboard.

Users can generate short links, create custom aliases, copy links instantly, generate QR codes and monitor usage statistics.

## Features

- Shorten long URLs instantly
- Custom short codes for links
- Click tracking and analytics
- QR code generation for each short link
- Copy shortened links to clipboard
- Link expiration system
- Real-time dashboard with statistics
- Search and filter links
- Sort links by popularity
- Delete links from dashboard
- Automatic cleanup of expired links

## Dashboard Capabilities

The dashboard provides an overview of link activity and analytics:

- View all generated short links
- Track total clicks for each link
- Visualize popular links through charts
- Search and filter links easily
- Sort links based on click count
- Monitor link expiration status
